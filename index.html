Acessibilidade Web (WCAG) Módulo 2: Percepção

Princípio 1: Perceptível

As informações da interface devem ser apresentadas de forma que todos possam percebê-las (Visão, Audição, Toque).

O primeiro princípio do WCAG garante que o conteúdo não seja "invisível" para nenhum dos sentidos do usuário. Pense nas Heurísticas de Nielsen: o sistema precisa manter o usuário informado, e isso só é possível se ele consegue perceber a informação.

Diretrizes Principais

  • Alternativas em Texto (1.1): Tudo que não for texto (imagens gráficos no Power BI, ícones) deve ter uma alternativa descritiva (`alt`).
  • Mídia Baseada em Tempo (1.2): Forneça legendas, transcrições ou audiodescrição para vídeos e áudios.
  • Adaptável (1.3): Crie conteúdo que possa ser apresentado de diferentes formas (ex: layout simplificado) sem perder a informação ou estrutura. Uso correto de tags semânticas no HTML.
  • Distinguível (1.4): Facilite a visualização e audição. O contraste de cor deve ser no mínimo 4.5:1 (relação com cores de marca, ex: azul petróleo e branco).

Aplicação em Next.js / React

Ao desenvolver componentes, evite usar apenas cores para transmitir status de erro. Utilize ícones + texto descritivo e a tag aria-live="polite" para leitores de tela.
